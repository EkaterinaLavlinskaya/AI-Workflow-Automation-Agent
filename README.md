# AI-Workflow-Automation-Agent
Цель 
Разработать прототип интеллектуального ассистента, способного интерпретировать команды на естественном языке, планировать их выполнение и безопасно запускать утилиты локальной ОС или обращаться к внешним API, обеспечивая автоматизацию рутинных задач разработчика и офисного сотрудника.
