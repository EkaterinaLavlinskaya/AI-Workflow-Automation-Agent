# AI-Workflow-Automation-Agent
Цель проекта
Разработать прототип интеллектуального ассистента, способного интерпретировать команды на естественном языке, планировать их выполнение и безопасно запускать утилиты локальной ОС или обращаться к внешним API (OpenAI-compatible), обеспечивая автоматизацию рутинных задач разработчика и офисного сотрудника.

Описание проекта
Разработать модульную систему «AI-агент», которая выступает прослойкой между пользователем и рабочей средой. Система должна включать:
Модуль интерфейса: CLI (Command-Line)-утилита или легковесный GUI (Text-based UI/Web) для ввода задач на естественном языке.
Оркестратор задач (Core): сервис, который формирует контекст, взаимодействует с LLM (через OpenAI-compatible API) и парсит ответ модели для построения плана действий.
Исполнительный модуль (Local Executor): защищённый компонент для запуска локальных утилит (bash/powershell скрипты, системные команды, работа с файловой системой) с реализацией песочницы (sandbox) и контролем прав доступа.
Шлюз внешних интеграций: модуль для безопасного взаимодействия с внешними API (календарь, Jira, AI-провайдеры) с управлением ключами и ротацией токенов.
Подсистему сбора метрик и логирования: запись действий агента, времени отклика, успешности выполнения шагов для последующего анализа (метрики для data-driven подхода).
Механизм верификации: возможность A/B-тестирования разных системных промптов или моделей для оценки качества генерации команд.
